# Lesson 5: 가산 규칙 — 언제, 얼마나 더 받을 수 있나?

> 야간에 약을 조제하면 낮보다 더 받는다. 가루약을 만들면 별도 가산이 붙는다. 8가지 가산의 종류, 어떤 게 점수 위에 곱해지고 어떤 게 점수에 더해지는지, 그리고 우선순위 규칙을 배웁니다.

## 🎯 이 레슨의 목표
- 가산의 8가지 종류와 각각의 적용 조건을 설명할 수 있다
- 가산 우선순위 규칙(배타·중복·예외)을 이해하고, 여러 조건이 겹칠 때 어떤 가산이 적용되는지 판단할 수 있다
- 6세 가산이 "점수 별도 합산", 토요 가산이 "별도 라인 분리 청구"인 이유를 구분할 수 있다

## 📚 시작하기 전에

이 레슨은 **Lesson 4: 조제료 이해하기 (Z코드)** 를 먼저 읽고 오시는 걸 권장합니다. 가산은 조제료 점수 위에 얹히는 추가 요금이라, 조제료 Z코드 구조를 이미 알면 훨씬 이해하기 쉽습니다.

## 1. 왜 가산이 존재할까? (The Why)

오후 2시에 약국을 찾는 것과 밤 11시에 약국 문을 두드리는 것은 다릅니다. 심야에 문 여는 약국은 인건비도 더 들고 약사도 힘듭니다. 가루약을 만드는 건 완제 알약을 그냥 봉투에 담는 것보다 손이 훨씬 많이 갑니다. 6세 미만 아이에게 조제하는 것도 용량 계산이 까다롭습니다.

**건강보험 제도는 이 차이를 인정합니다.** 일반적인 낮 시간대 조제보다 더 어렵거나 부담 큰 상황엔 기본 조제료에 추가 금액을 붙여줍니다. 이것이 **가산(加算)**입니다.

가산을 이해하면 약국 영수증의 "Z2000010" 같은 코드 뒤 숫자들이 자연스럽게 읽힙니다. 그 접미사 숫자들이 어떤 가산이 적용됐는지를 나타내는 신호입니다.

## 2. 8가지 가산 한눈에 보기 (The What)

| # | 가산 종류 | 적용 조건 | 산정코드 특징 | 적용 방식 |
|---|---------|---------|------------|---------|
| 1 | **야간 가산** | 평일 09시 이전·18시 이후 / 토요 13시 이후 | 접미사 `010` | 기본점수 × 30% |
| 2 | **공휴일 가산** | 법정 공휴일 | 접미사 `050` | 기본점수 × 30% (야간 흡수) |
| 3 | **토요 가산** | 토요 09~13시 (야간/공휴 미해당 시) | 접미사 `030`, **별도 라인** | 별도 라인 분리 청구 |
| 4 | **6세 미만 가산** | 환자 6세 미만 | 접미사 `600` (단독) / `610` / `650` | **+6.67점 별도 합산** (Z2000 한정) |
| 5 | **소아 심야 가산** | 6세 미만 + 20시~익일 07시 | 접미사 `64x` (2023.11.01~) | Z20/Z30 200%, Z40 100% |
| 6 | **가루약(산제) 가산** | 가루약 조제일수 ≥ 1일 | 내복조제료(Z41/Z43)에 적용 | 다른 가산 전부 무력화 |
| 7 | **비대면 조제 가산** | 약물안전서비스 첫 자리 = "U" | ZC001~ZC004 (관리료 1,100원) | 기존 가산 전부 무력화 + 별도 코드 |
| 8 | **차등수가** | 약국 영업시간 기반 (보험코드 C 한정) | Z1000(약국관리료) 접미사 변경 | 차등미적용=`text3=1` |

> 💡 **팁**: 코드 접미사 한 자리씩 읽으면 어떤 가산인지 보입니다 — `text(연령)` + `text2(시간)` + `text3(차등)`.
> - text="6" → 6세 미만, "0" → 기타
> - text2="1" → 야간, "2" → 심야, "3" → 토요, "5" → 공휴
> - text3="1" → 차등 미적용, "0" → 차등 해당 or 비대상
>
> 예: `Z2000610` = 6세(6) + 야간(1) + 차등해당(0)

## 3. 각 가산 자세히 살펴보기

### 3-1. 야간 가산 — "늦게까지 열어줘서 고맙습니다"

야간 가산의 기준 시간은 다음과 같습니다.

- **평일**: 09시 이전 또는 18시 이후
- **토요일**: 09시 이전 또는 **13시 이후**

평일 19시에 처방전을 가지고 약국에 갔다면 야간 가산이 붙습니다. 토요일 14시도 마찬가지로 야간 가산 시각.

가산 금액 공식 (예: Z2000):
```
최종점수 = 기본점수 × (1 + 0.30)
금액 = Round1(기준금액 × 최종점수)
```
예시: `16.26 × 1.30 × 105.5 = 2,229.9원 → 2,230원` (Z2000010)

> ⚠️ **중요: 일반 성인 심야 가산은 없습니다.** 18시~익일 09시 사이는 전부 "야간 가산" 하나로 처리됩니다. 심야 가산은 **6세 미만 전용**이며, 일반 성인용 심야 가산 코드 자체가 존재하지 않습니다.

### 3-2. 공휴일 가산 — "쉬는 날 나와줘서 고맙습니다"

법정 공휴일에는 공휴일 가산이 적용됩니다. 계산은 야간과 동일(30%)하지만 접미사가 `050`. 공휴일은 시간대와 관계없이 **야간 가산을 흡수**합니다.

> ⚠️ **주의**: 야간과 공휴일 가산은 **배타적**입니다. 공휴일 야간이라도 공휴일 가산 하나만 붙습니다.

### 3-3. 토요 가산 — "오전엔 좀 받아갑니다"

**판정 조건**: 토요 09시~13시 사이, **야간/공휴 미해당** 시.

> 🔑 **핵심: 토요 가산은 다른 가산과 다르게 "별도 라인 분리 청구"입니다.**
>
> 다른 가산(야간/공휴/소아심야)은 기본 조제료 코드 하나에 모든 가산이 녹아든 단일 라인입니다. 반면 토요 가산은:
> - **기본 라인**: `Z4103` 또는 `Z2000` (기본 접미사)
> - **토요 가산 라인**: `Z4103030` 또는 `Z2000030` (접미사 `030` 별도 레코드)
>
> 두 라인을 **EDI 명세서에 각각 따로** 기재해야 합니다. 합산 또는 내재 시 심사 부적합.

**토요 + 야간 동시 적용 (HIRA 공식 규정)**: 토요 13시 이후 조제 시 **야간가산 라인 + 토요가산 라인 동시 청구**.

예: 토요 14시 내복 7일분 조제 → `Z4103011` (내복+야간) + `Z4103030` (토요) 두 라인 모두 명세서에 기재.

**토요 + 공휴 동시**: 공휴 가산만 적용 (배타).

### 3-4. 6세 미만 가산 — "+6.67점 별도 합산"

6세 미만 아이에게 조제할 때는 소아 가산이 추가됩니다. 가루약을 먹이는 경우가 많고 용량 계산이 까다롭기 때문입니다.

> 🔑 **핵심: 6세 가산은 "점수에 곱하지 않고 별도로 더합니다".**
>
> 다른 가산은 "기본점수 × 가산률" 곱셈이지만, 6세 가산은:
> ```
> 최종점수 = (기본점수 × 다른가산률) + 6.67점
> ```
> 6.67점이 가산률 곱셈 **밖에서** 별도 합산됩니다. 그리고 이 6.67점 합산은 **조제기본료 Z2000에만** 적용됩니다(Z3000/Z4xxx에는 별도 6세 점수 없음).

산식 검증:
| 코드 | 산식 | PZCVALUE |
|---|---|---:|
| Z2000600 (6세 일반) | `(16.26 + 6.67) × 105.5 = 2,419` → **2,420원** | 2,420 ✓ |
| Z2000610 (6세+야간) | `(16.26 × 1.30) + 6.67 = 27.808 → ×105.5 = 2,933.7` → **2,930원** | 2,930 ✓ |

**중복 가능 범위:**
- 야간/공휴 가산 + 6세 가산 (Z2000610, Z2000650)
- 소아심야 + 6세 (이미 200% 가산 안에 포함)

**미적용 (6세 가산 사라지는 경우):**
- **가루약 가산 시** (공단 고시 (11) 명시: "가루약과 중복하여 산정하지 아니한다")
- **토요 가산 시**: Z2000030(일반 토요)과 Z2000630(6세+토요)이 동일하게 510원. 토요는 "별도 산정"이라 6세 가산 6.67점이 합산되지 않음.

### 3-5. 소아 심야 가산 — "6세 미만 전용"

**판정 조건**: 6세 미만 + 20시~익일 07시.

**가산률** (공단 고시 (9), 2023.11.01 이후):
| 대상 | 가산률 | 두 번째 자리 코드 | 점수 |
|---|:---:|:---:|---|
| **조제기본료(Z2000) · 복약지도료(Z3000)** | **200% 가산** | "4" | 기본 × 3 |
| **조제료(Z4xxx)** | **100% 가산** | "2" | 기본 × 2 |

산식 검증:
- Z2000640 (6세 심야 Z20): `(16.26 × 3.00 + 6.67) × 105.5 = 5,849.9` → **5,850원** ✓
- Z4101020 (6세 심야 Z40 1일분): `17.20 × 2.00 × 105.5 = 3,629.2` → **3,630원** ✓

> **6세 이상이 심야에 오면?** 심야 플래그를 야간으로 다운그레이드해 일반 야간 가산만 적용. 일반인 심야 가산은 제도상 존재하지 않습니다.

### 3-6. 가루약 가산 — "다른 가산 전부 무력화"

**판정 조건**: 가루약(산제) 약품이 존재 AND 가루약 조제일수 ≥ 1일.

**적용 범위**: **내복조제료(Z41/Z43)에만** 적용. 조제기본료(Z2000), 복약지도료(Z3000), 외용조제료(Z4120)엔 미적용.

> 🔑 **핵심: 가루약 가산이 적용되면 다른 가산은 전부 미적용.**
>
> - 야간/공휴 가산: 미적용
> - 소아심야 가산: 미적용
> - 토요 가산: 미적용
> - **6세 가산: 미적용** (공단 고시 (11) + 유팜 `Check소아가산_조제료` 로직)

이는 "제형변경이 불가피하여 가루약으로 조제하는 경우" 별도의 가산 체계로 분리한 결과입니다.

### 3-7. 비대면 조제 가산 — "ZC 코드로 완전 교체"

**판정 조건**: 약물안전서비스(`DrugSafe_YN`) 첫 자리 = "U". 2023.06.01 시행.

**코드 결정 우선순위**:
1. 공휴 → **ZC004** (최우선)
2. 야간이면서 20시~07시 → **ZC003** (심야)
3. 야간 (그 외) → **ZC002**
4. 일반 → **ZC001**

> ✅ **4개 코드 모두 점수 10.40점, 단가 1,100원으로 동일** (2026년 환산지수 105.5원 기준). 시간대 구분은 산정지침 분류일 뿐 점수는 같습니다. 출처: 공단 PDF 「2025-736 비대면진료 시범사업 약국용 지침 개정본」 페이지 21 표 직접 추출.

**비대면 적용 시 효과**:
- 모든 가산(야간/공휴/소아/소아심야/토요/가루약) 비활성화
- 시간 플래그 자체가 흡수돼 false 처리
- 코로나19 투약안전관리료 미산정
- ZC001~ZC004 관리료 1,100원이 약제비에 **추가**됨 (약-1~약-5는 그대로 산정)

### 3-8. 차등수가 — "약국 영업시간 기반 미세 가감"

차등수가는 약국의 영업시간 기준으로 산정되며, **보험코드 첫 자리 = "C"(건강보험)** 인 경우만 대상. 산정코드 세 번째 자리(`text3`)에 반영됩니다.

| 상황 | `text3` |
|---|:---:|
| 차등 미적용 (영업시간 길이 ≥ 8시간 등) | "1" |
| 비해당 (C 외 보험) | "0" |
| 차등 해당 (기본) | "0" |

복잡한 규정이라 실무에서는 청구 시스템이 자동 판단합니다. 시험 출제 빈도는 낮은 편이지만, `text3` 의미를 읽을 줄 알면 영수증 해석이 쉬워집니다.

## 4. 가장 중요한 것: 우선순위 규칙 (The How)

여러 조건이 동시 해당할 때 어떤 가산을 적용할지는 엄격한 우선순위로 결정됩니다.

### 우선순위 요약도

```
조건 확인 시작
     ↓
① 비대면(DrugSafe_YN="U")? → YES → ZC계열 코드로 완전 교체, 다른 가산 전부 종료
     ↓ NO
② 가루약(산제) 처방? → YES → 가루약 가산만 적용, 야간/공휴/소아/토요 전부 배제
     ↓ NO
③ 공휴일? → YES → 공휴 가산만 (야간 흡수)
     ↓ NO
④ 6세 미만 + 20시~07시? → YES → 소아심야 가산 (200%/100%)
     ↓ NO
⑤ 야간 시간대(평일 9시前/18시後, 토요 9시前/13시後)? → YES → 야간 가산
     ↓ (동시에)
⑥ 토요 09~13시(야간/공휴 미해당)? → YES → 토요 가산 (별도 라인)
     ↓ (동시에)
⑦ 토요 13시 이후? → 야간 + 토요 두 라인 모두 청구

[별도] 6세 미만이면 ②/토요(⑥) 를 **제외**한 ③/⑤와 중복 적용
       (+ Z2000에 한해 6.67점 별도 합산)
```

> **정리**:
> - **가루약**이 있으면 다른 가산 전부 무력화 (소아조차 미적용).
> - **6세 가산 6.67점**은 토요/가루약 조합에서만 사라짐. 야간/공휴와는 공존.
> - **토요 13시 이후**는 야간과 동시 청구 (별도 라인 두 개).

### 예시 ①: 평일 19시, 30세 환자, 일반 알약

- 평일 19시 → 야간 시간대 (18시 이후)
- 6세 미만? 아니오
- 가루약? 아니오 / 비대면? 아니오

**결론**: 야간 가산 1개. 조제기본료 코드 `Z2000010`.

### 예시 ②: 토요 11시, 4세 환자, 일반 알약 (수정됨)

- 토요 11시 → 09~13시 → 토요 가산 해당
- 4세 → 6세 미만
- 가루약? 아니오

**결론**: 토요 가산 단독 (별도 라인). 6세 가산은 토요와 결합 시 **미적용** (CH04 §4-3 검증: Z2000030 = Z2000630 = 510원 동일).

조제기본료 코드: `Z2000030` (토요), 그리고 기본 라인 `Z2000`은 6세 단독 가산(`Z2000600`)이 아니라 그냥 `Z2000` 기본으로 청구.

> ⚠️ **흔한 오해**: "6세+토요면 둘 다 적용되겠지" → 아니오. 토요만 적용됩니다.

### 예시 ③: 토요 14시, 30세 환자, 내복 7일분

- 토요 14시 → 13시 이후 → **야간 + 토요 동시**
- 6세 미만? 아니오

**결론**: **두 라인 청구**.
- 야간 라인: `Z4103011` (내복+야간)
- 토요 라인: `Z4103030` (토요, 별도)

### 예시 ④: 평일 20시, 4세 환자, 일반 알약

- 평일 20시 → 18시 이후 + 20시 이후 → 소아심야 시간대
- 4세 → 6세 미만
- 가루약? 아니오

**결론**: **소아심야 가산** (Z2000 200% + 6.67점 별도). 코드 `Z2000640`, 5,850원.

### 예시 ⑤: 공휴 22시, 8세 환자, 일반 알약

- 공휴 → 공휴 가산만 (시간대 무관)
- 8세 → 6세 미만 아님
- 가루약? 아니오

**결론**: 공휴 가산만. `Z2000050`.

## 6. 지식 체크

**Q1.** 토요일 14시, 만 3세 아이가 가루약 처방을 가지고 약국에 왔습니다. 이때 적용되는 가산은?

① 토요 가산 + 소아 가산  
② 야간 가산 + 토요 가산 + 소아 가산  
③ 가루약 가산만 적용  
④ 야간 가산 + 가루약 가산

<details>
<summary>정답 확인</summary>

**정답: ③** — 가루약이 있으면 가루약 가산이 최우선이고 다른 모든 가산(야간/소아/토요)이 배제됩니다. 비록 토요 14시(야간+토요 동시 시간대)이고 3세 소아이더라도, 가루약 가산 하나만 적용됩니다.

</details>

<!-- KNOWLEDGE_CHECK:id=lesson05-check2 -->

**Q2.** 토요일 11시, 만 4세 아이가 일반 알약 처방을 가지고 왔습니다. 어떤 코드가 청구될까요?

① `Z2000630` (6세+토요)  
② `Z2000030` (토요 단독)  
③ `Z2000600` (6세 단독) + `Z2000030` (토요)  
④ `Z2000610` (6세+야간)

<details>
<summary>정답 확인</summary>

**정답: ②** — 6세 가산은 토요 가산과 결합되지 않습니다. PZCVALUE 검증 결과 Z2000030(일반 토요)과 Z2000630(6세+토요) 단가가 동일(510원)하기 때문에, 토요 시간대 6세 환자는 토요 라인만 별도로 청구되고 기본 라인은 평범한 `Z2000`으로 처리됩니다.

</details>

<!-- KNOWLEDGE_CHECK:id=lesson05-check3 -->

**Q3.** 공휴일 22시, 만 8세 환자가 일반 알약 처방전을 가지고 왔습니다. 어떤 가산이 적용될까요?

① 야간 가산만  
② 공휴일 가산만  
③ 야간 + 공휴일 동시  
④ 소아 심야 가산

<details>
<summary>정답 확인</summary>

**정답: ②** — 야간과 공휴일은 배타적이고, 공휴일이면 시간대와 관계없이 공휴 가산 하나만 적용됩니다. 8세이므로 6세 미만 가산도 미해당. 일반 성인 심야 가산은 제도상 존재하지 않습니다.

</details>

<!-- KNOWLEDGE_CHECK:id=lesson05-check4 -->

**Q4.** 토요일 15시, 30세 환자, 내복 7일분 처방을 받았습니다. 청구 라인은 몇 개일까요?

① 1개 (`Z4103030` 토요)  
② 1개 (`Z4103011` 야간)  
③ 2개 (`Z4103011` 야간 + `Z4103030` 토요)  
④ 1개 (`Z4103530` 야간+토요 결합)

<details>
<summary>정답 확인</summary>

**정답: ③** — HIRA 공식 규정상 토요 13시 이후는 **야간 + 토요 동시 청구**이며, 토요 가산은 별도 라인이라 두 라인을 명세서에 따로 기재해야 합니다. 결합 코드 `Z4103530` 같은 건 존재하지 않습니다.

</details>

## 🎓 이 레슨에서 배운 것

- 가산 8종류: 야간 · 공휴 · 토요 · 6세 미만 · 소아심야 · 가루약 · 비대면 · 차등수가
- 가산 코드는 접미사로 구분: `text(연령)·text2(시간)·text3(차등)`
- **우선순위**: 비대면 → 가루약 → 공휴 → 소아심야 → 야간 → 토요 (야간과 토요는 동시 가능)
- **6세 가산은 점수 곱이 아닌 +6.67점 별도 합산** (Z2000 한정)
- **토요 가산은 별도 라인 분리 청구**, 야간과 동시 가능
- **가루약 가산이 적용되면 6세를 포함한 다른 모든 가산 배제**
- **일반 성인 심야 가산은 없음** (심야 가산은 6세 미만 전용)
- **비대면 ZC001~ZC004 4개 코드 모두 1,100원 동일** (시간대는 분류만 다름)
